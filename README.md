# el-cloud-minimart-architecture
MiniMart Cloud Capstone Project
## Architecture Overview

This project presents a scalable cloud-native e-commerce architecture for MiniMart Cloud using Microsoft Azure.

The system uses Azure Static Web Apps for the frontend, API Management as a gateway, and Azure App Service for backend services. Data is managed using Azure SQL Database and Azure Blob Storage, while Azure Service Bus enables asynchronous processing for scalability.
