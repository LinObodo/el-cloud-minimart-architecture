# Functional Requirements

- Users can browse products
- Users can search/filter products
- Users can add/remove items to cart
- Users can place orders
- Users can make payments
- Users receive order confirmation

# Non-Functional Requirements

- Scalability: Handle high traffic spikes
- Availability: 99.9% uptime
- Performance: Fast response time (<2 seconds)
- Security: Secure APIs and encryption
- Reliability: No data loss during peak events
- Cost: Pay-as-you-use cloud services
- Maintainability: CI/CD enabled deployments
