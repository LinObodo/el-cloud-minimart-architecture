
# MiniMart Cloud – System Overview

MiniMart Cloud is an online grocery and household items platform transitioning from a basic website to a scalable cloud-native architecture on Microsoft Azure.

The goal is to build a secure, scalable, and reliable system capable of handling high traffic during peak periods such as holidays, weekends, and promotional campaigns.

The platform will support:
- Product browsing and search
- Shopping cart management
- Order placement
- Payment processing
- Order notifications

The proposed solution leverages Azure managed services to ensure high availability, scalability, and cost efficiency.
